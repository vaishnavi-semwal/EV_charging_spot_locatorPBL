⚡ EV Charging Spot Locator

A Data Structures & Algorithms Based PBL Project

📌 About the Project

EV Charging Spot Locator is a DSA-based project designed to help electric vehicle users find suitable charging spots according to their current location, battery level, and charging requirements.

The project demonstrates how Data Structures and Algorithms can be applied to solve a practical real-world problem related to electric vehicle charging.

🎯 Objectives

- Locate suitable EV charging spots efficiently.
- Consider the vehicle's current battery level.
- Help users identify reachable charging stations.
- Apply DSA concepts to a real-world problem.
- Provide an efficient and structured approach to charging-station selection.

🧠 DSA Concepts Used

- Graphs – To represent locations and connections between charging spots.
- Nodes & Edges – To represent charging stations and routes.
- Searching Algorithms – To find suitable charging locations.
- Arrays / Lists – To store and manage charging-station information.
- Traversal Algorithms – To explore connected locations.

⚙️ How It Works

1. The system takes the vehicle's current information as input.
2. Charging stations and their connections are represented using suitable data structures.
3. The system checks which charging spots are reachable.
4. Suitable charging stations are searched based on the given requirements.
5. The most appropriate charging spot is displayed as the result.

🚀 Key Features

- 🔋 Battery-based charging spot selection
- 📍 Location-based station identification
- 🔎 Efficient searching
- 🧩 Practical implementation of DSA
- 🌱 Focused on EV infrastructure and smart mobility

🛠️ Technologies Used

- Programming Language: C / C++
- Core Concepts: Data Structures & Algorithms
- Development Environment: VS Code
